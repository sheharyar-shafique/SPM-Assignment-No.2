# Campus Study Room Booking System (CSRBS)

FAST-NUCES | CS4002 Fundamentals of Software Project Management | Assignment 02

## Project purpose

A web application for campus students to register, log in, find study rooms, and manage room bookings. The project follows Scrum planning in Jira.

## Planned technology stack

Node.js, Express, SQLite, HTML, CSS, JavaScript.

## Jira

Project: https://cfd-team-v7zzd0yx.atlassian.net/jira/software/projects/CSRBS

## Development workflow

Create one feature branch per Jira story using the issue key (e.g. `CSRBS-7-student-registration`). Reference the key in commit messages and pull requests. Each member must contribute their own code and review the other's pull requests before merge.

> The app implementation will be added in the relevant Jira-linked feature branches.
